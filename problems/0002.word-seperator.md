For this challenge you will need to design a program that accepts 
as input a sentence in which all the words are run together, but the first character of each word is uppercase. 
Your program will need to convert the sentence to a string in which the words are separated by spaces whenever an uppercase letter is detected and only the first word starts with an uppercase letter.

For example, the string “StopAndSmellTheRoses.” would be converted to Stop and smell the roses”.

The program will need to work through the string looking for uppercase letters (ignoring the first character of the string) and when an uppercase letter is detected that will indicate a new word where a space needs to be added. The converted sentence with spaces will then be displayed back to the user.
