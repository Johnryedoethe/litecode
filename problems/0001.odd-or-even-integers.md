For this challenge, you need to complete the following tasks:

1. Write a program that is capable of determining if numbers are odd or even.
This means that you cannot just display a list of numbers one by one or
use a loop to display numbers within a range using an increment*.
Your program must actually be able to determine if numbers are odd or even.
2. The program shall then display the even numbers from 0 to 50
3. The program shall then display the odd numbers from 0 to 50.

## Sample solution structure

```js
function solution(numbers) {
  return {
    odds: [...],
    evens: [...]
  }
}
```

## Sample input

```json
[1, 2, 3]
```

## Sample output

The output of your program may look something like this:

```json
{odds: [1, 3], evens: [2]}
```
